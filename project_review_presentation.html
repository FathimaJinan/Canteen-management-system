01

Problem Statement & Motivation

Long Waiting Lines

Students waste valuable recess/break times waiting in long physical queues at multiple canteen outlets.

Time Inefficiency

Cash Handling Bottlenecks

Manual currency exchange, searching for small change, and verifying physical receipts slows down order booking.

Operational Friction

Canteen Admin Overhead

Shop owners struggle to track incoming orders, compute sales statistics, and manage preparation queues in real-time.

Management Chaos
Project Goal: Create a system that allows students to pre-order food, choose an estimated pick-up time, pay securely online, and skip queues completely while canteen owners manage orders seamlessly.
02

The Zappadu Proposed Solution

✓

Unified Multi-Vendor Dashboard

Students browse menus from 3 different canteen shops (South Indian, North Indian, Snacks & Juice Bar) on a single platform.

✓

Pre-Payment Simulator (Razorpay API Mock)

Fully interactive checkout modal supporting UPI, Card, Net Banking, and Wallet, mimicking payment delays and error rates.

✓

Real-Time State Tracker

Active status notifications showing order progression (Pending → Preparing → Ready → Collected).

Key System Benefits

  • 90% Time Saved: Students grab food directly when ready.
  • 0% Cash Mistakes: Auto-ledger ledger logging.
  • Optimized Food Prep: Shops know exact queues in advance.
  • Local Reliability: Offline-first storage safeguards student session data.

System Architecture & Tech Stack

Core Frontend
React 18

Declarative component hierarchy with Virtual DOM rendering

Language Security
TypeScript

Strict static typing for menu items, users, and orders

Styling Engine
Tailwind CSS

Utility-first styling with shadcn/ui custom UI layout library

Persistence
LocalStorage

Device ledger database maintaining order logs & wallet balances

Context-Driven State Flow

AuthContext (Active User, Roles, Wallet Balance) → CartContext (Custom items, Quantity, Current Shop ID) → OrderContext (Place Order, Status, LocalStorage sync)

Shop Owner Dashboard

State Pipeline Controls ORDER LIFE-CYCLE

Shop owners control their active queues through quick-action button transitions:

1. NEW ORDER (Pending) → Accept
2. ACTIVE (Accepted) → Start Preparing
3. PREPARING (In Progress) → Mark Ready
4. READY (Awaiting Pickup) → Collected

Business Analytics Panel

  • Real-Time Sales Counter: Active tabs classify orders automatically
  • Automatic Revenue Ledger: Total gross daily revenue dynamically summed
  • Multi-Vendor Security Scope: Owners only see orders placed for their specific shopId

Integrated Payment Simulators

Prepaid Canteen Wallet Ledger

An internal digital ledger simulating instant wallet deduction and quick checkout.

  • • Instant Checkout: Order confirmation takes <1 second.
  • • 0% Fee Policy: Wallet orders incur zero transaction surcharges.
  • • Device Ledger: History logs top-ups and deductions on-device.
Simulates fast internal databases

Razorpay API Sandbox Mock

Simulates a live integration with payment aggregators like Razorpay.

  • • Fee Rules: Cards/Net banking add 2% fee + 18% GST.
  • • 3D-Secure Processing: 5-second simulated loading state.
  • • Error Scenarios: User cancellation simulation handles failures gracefully.
Simulates API response latencies

Conclusion & Future Scope

Project Conclusion

Zappadu addresses critical student pain points of line delays and cash management in a high-efficiency digital environment. The React frontend is highly modular, separating authentication, cart managers, order trackers, and payment gateways cleanly via Context providers.
